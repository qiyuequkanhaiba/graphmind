# 专业知识图谱关系分析视图设计规格

## 背景

GraphMind 当前已具备表格导入、关系推断、证据检查、中文界面、示例数据导入和节点拖拽。下一步目标是把中心图谱从“节点连线展示”升级为更专业的关系分析工作台，方向选择为 A：GitNexus 式均衡工作台，并吸收 ERD 表卡片的信息密度。

## 目标

1. 默认进入“关系分析”视图，让用户首先看到表与关键关系。
2. 表节点升级为专业分析卡片，展示行数、字段数、关系数和关键字段数。
3. 关系边按语义和强度呈现，外键边突出，结构边弱化。
4. 图谱控制条更像分析控制台，支持关系强度快速筛选。
5. 保留已实现的节点拖拽，并新增“重置布局”让用户回到自动布局。

## 非目标

1. 本轮不引入 3D 图谱。
2. 本轮不做完整 Neo4j Bloom 式聚类动画。
3. 本轮不把手动布局持久化到后端。
4. 本轮不重写右侧证据面板。

## 用户体验

用户进入工作台后，中心图谱默认使用“关系分析”模式：

- 表节点比字段节点更醒目。
- 表节点内部显示数据摘要。
- 强外键边显示 `外键 · 99%` 等标签。
- `contains_field` 结构边保留但视觉弱化。
- 顶部控制条可快速切换全部、强关系、待审核。
- 用户拖乱图谱后可点击“重置布局”恢复自动布局。

## 前端设计

### 视图模式

`GraphCanvas` 的 `ViewMode` 新增 `analysis`，并作为默认值。

分析模式下：

- `table`、`field`、`derived_entity` 都可显示。
- 外键和派生维度边显示。
- `contains_field` 边显示但弱化。

### 节点摘要

`SemanticNode` 接收增强后的 `data`：

- `graphNode`
- `highlighted`
- `relationshipCount`
- `keyFieldCount`

表节点展示：

- 表名
- 行数和字段数
- 关联关系数
- 关键字段数

字段节点展示：

- 字段名
- 类型
- 键候选分

维度节点展示：

- 维度名
- 不同取值数

### 关系强度

新增前端关系强度判断：

- `strong`: `confidence >= 0.9` 或 evidence payload 中 `relationship_strength === "strong"`
- `likely`: `confidence >= 0.8`
- `possible`: 其他建议关系

边 class 增加：

- `edge-strength-strong`
- `edge-strength-likely`
- `edge-strength-possible`
- `edge-structural`

强关系线条更亮，结构边更细、更透明。

### 控制条

新增强度快速筛选：

- 全部
- 强关系
- 待审核

新增“重置布局”按钮：

- 清空 `manualNodePositions`
- 调用 `fitView`
- 保留当前筛选和视图模式

### 测试

新增或更新前端测试：

- 默认视图为关系分析。
- 表节点显示关系数和关键字段数。
- 强关系边拥有强度 class。
- 结构边拥有弱化 class。
- 强关系筛选只显示强关系。
- 重置布局清空拖拽位置。

## 验收标准

1. 打开工作台默认显示“关系分析”模式。
2. 示例数据中的 `Orders` 表节点显示表摘要和关系摘要。
3. `Orders.customer_id -> Customers.id` 外键边视觉上比结构边更突出。
4. 强关系筛选可以隐藏非强关系。
5. 拖动节点后点击“重置布局”可恢复自动布局。
6. 前端测试、类型检查、构建通过。
