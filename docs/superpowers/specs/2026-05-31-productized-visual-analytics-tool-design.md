# GraphMind 产品化可视化分析工具升级设计

日期：2026-05-31
状态：第三阶段进行中

## 背景

GraphMind 已完成 GitNexus workbench 风格的基础工作台：数据树、关系图谱、证据/审核/AI 侧栏、中文默认、多端基础适配、AI 和向量配置入口、关系证据链。下一阶段目标是从“单页原型工作台”升级为可长期演进的专业可视化产品。

对齐方向参考主流图谱和 BI 工具：

- Neo4j Bloom：Perspective、搜索、探索、检查、图谱保存和分享。
- Linkurious：调查型 workspace、筛选、撤销/重做、导出、评论、时间线。
- Graphistry：大规模图谱探索、模板化 investigation、AI 辅助图谱分析。
- Power BI Mobile：桌面完整创作，移动端偏查看、搜索、轻交互和专用视图。

## 产品原则

1. 主画布优先：图谱区域是核心资产，辅助功能以抽屉、弹窗、独立页面承载。
2. 工作流闭环：导入建模、关系探索、AI 问答、证据审核、保存分享形成连续路径。
3. 多端分层：桌面完整工作台，平板使用模块化侧栏，手机优先图谱查看和轻量问答。
4. 可解释可信：每条关系都需要来源、置信度、证据和审核状态。
5. 产品一致性：统一颜色、间距、按钮、面板、图谱节点、空/加载/错误状态。

## 目标信息架构

- 工作台：图谱探索、筛选、路径分析、证据查看和 AI 问答。
- 数据导入：上传向导、字段画像、主键/外键候选、关系建议。
- 关系建模：建议审核、关系编辑、规则配置、证据质量。
- AI 配置：LLM Provider、Embedding Provider、向量索引、引用策略。
- 项目设置：语言、导出、视图快照、项目元数据。
